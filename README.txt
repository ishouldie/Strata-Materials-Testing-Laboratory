STRATA MATERIALS TESTING LABORATORY - WEBSITE PROJECT
====================================================================

Project:
--------
Strata Materials Testing Laboratory Website

Purpose:
--------
ESC 31 Computer Fundamentals and Programming Laboratory Midterm Project

This is a fictional civil engineering materials testing laboratory
website created for academic purposes. Strata, its services, staff,
sample projects, and contact details are NOT real. Any resemblance to
an actual company is coincidental. Contact fields are intentionally
left as placeholders (e.g. "[Insert Phone Number]") and should be
replaced only with real information if this project is ever adapted
for actual use.

Pages Included:
----------------
1. index.html            - Home page
2. about.html             - About Strata (mission, vision, intro)
3. services.html          - Our Services
4. testing-process.html   - Our Testing Process (4-step timeline)
5. equipment.html         - Laboratory Equipment
6. projects.html          - Project Gallery (sample projects)
7. contact.html           - Contact / Inquiry form

Technology Used:
-----------------
- HTML5 (semantic markup: header, nav, main/section, footer)
- CSS3 (single shared stylesheet, no framework)
- Vanilla JavaScript (no external JS libraries)
- Google Fonts: Montserrat (headings) and Poppins (body text)
- Custom hand-coded SVG logo and favicon
- Custom-generated illustrative images (abstract blueprint-style
  graphics created programmatically in the brand color palette,
  representing soil, concrete, aggregate, and compaction testing
  concepts)

Notes on Content:
-------------------
- All company facts (mission, vision, services, process, equipment,
  and sample projects) follow the project documentation provided for
  this assignment.
- No real clients, certifications, accreditations, licenses, or
  contact details are used anywhere in this project.
- The contact form performs client-side validation only (required
  fields, email format, service selection). It does not send a real
  email, since no backend or third-party form service is connected.
- The "Project Gallery" contains sample, non-client educational
  images and is clearly labeled as such on the page.
